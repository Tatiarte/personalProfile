## Tecnologías

- **HTML5:** estructura semántica (header, nav, main, section, article, footer).
- **Tailwind CSS (CDN):** diseño con clases de utilidad, con colores, fuentes y animación personalizados.
- **Bootstrap 5 (solo CSS):** grilla, tarjetas, insignias y botones en la sección de Proyectos.
- **Google Fonts:** Bricolage Grotesque, Hanken Grotesk y JetBrains Mono.
- **Git y GitHub:** control de versiones y alojamiento del código.

## Accesibilidad

- Atributo lang="es" y texto alternativo en la imagen.
- Navegación con aria-label y estilos focus-visible para uso con teclado.
- motion-reduce para desactivar animaciones.
